# Car Dodge CV Tasks

Game né ô tô 4 làn bằng **pygame + OpenCV + MediaPipe Tasks API**.
Tay  ở vị trí nào trong camera, xe sẽ lập tức chuyển sang làn tương ứng. Không cần bấm nút lấy tâm.


## Cài đặt

### macOS / Linux
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 main.py


###window
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
